# Free My TV — Melvin's build

Own build of [Free My TV](https://github.com/simbasjungles/free-my-tv) for the living-room TCL Google TV:

- Shelf as a macOS-style dock (magnification, labels, dots, All Apps)
- Now Playing card with the album art spinning like an LP

The releases here are what the TV's **Home Settings → Updates** installs. They are signed with this build's own key, so they only update this build (not the official release).
